## 总结

### WRITE 路径关键步骤

1. **边界检测** - LLM 判断是否到达话题边界
2. **并行提取** - 同时提取多种记忆类型（Episodes、Foresights、EventLogs）
3. **聚类触发** - 当 cluster 达到阈值时自动提取 Profile
4. **多数据库同步** - MongoDB → Elasticsearch → Milvus

### READ 路径关键步骤

1. **混合搜索** - 并行执行关键词和向量搜索
2. **重排序** - 使用 Rerank 模型提升结果质量
3. **批量查询** - 减少数据库往返次数
4. **重要性排序** - 基于 Profile 的 importance_evidence

### 性能优化

- ✅ 异步并行（`asyncio.gather`）
- ✅ 批量操作（`batch_get`）
- ✅ 缓存复用（MemCells、Profiles 字典）
- ✅ 连接池（数据库连接）

### 数据一致性

- ✅ MongoDB 为主存储
- ✅ ES 和 Milvus 为二级索引
- ✅ 事务支持（MongoDB）
- ✅ 同步失败重试机制
